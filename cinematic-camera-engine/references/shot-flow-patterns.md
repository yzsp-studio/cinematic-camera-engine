# 镜头流模板与变体 — Shot Flow Patterns

8 种经典镜头序列的**详细展开**：每种模板给出标准流、变体、节奏参数、
AI 视频注意事项，以及实战应用范例。

STEP 4 镜头流速查表命中模板后，来本文件获取完整的执行细节。

---

## 通用节奏规则

在展开具体模板前，先记住这些跨模板的通用规则：

| 规则 | 说明 |
|------|------|
| **呼吸法则** | 快切段落（每镜 ≤2s）后必须接一个长镜（≥4s）让观众喘息 |
| **开头稳定** | 镜头组的第 1 个镜头推荐 ≥3s + 固定/缓慢运镜，让观众"进入"场景 |
| **结尾收束** | 镜头组最后一镜推荐 ≥3s，给观众"着陆"的感觉 |
| **景别跨级** | 相邻镜头景别至少跨 2 级（中景→特写 ✓，中景→中近景 ✗） |
| **运镜方向一致** | 连续两镜的运镜方向不能 180° 反向（左移→右移 = 观众晕） |
| **动态密度递变** | 逐步加密或逐步稀疏，避免随机波动（快→慢→快→慢 = 混乱） |

### AI 视频特殊注意
- 单镜头时长建议 3-8s（AI 视频模型的最佳控制区间）
- 超过 8s 的长镜头→ AI 模型容易出现动作变形，考虑拆成 2 个镜头
- 快切段落中每镜 ≤2s 时→ 确保每镜头的主体和动作足够简单（一个镜头一件事）
- 景别跨级在 AI 视频中尤其重要：跨 1 级的画面差异 AI 模型可能生成几乎一样的构图

## 模板 1: 渐进揭示（Progressive Reveal）

**适用**：角色入场、环境建立、开场序列、从未知到已知

### 标准流
```
Shot 1: 远景（Wide Shot）— 固定 3-5s — 建立空间
Shot 2: 全景（Full Shot）— 缓推 3-4s — 锁定人物在空间中的位置
Shot 3: 中景（Medium Shot）— 固定或微推 3-4s — 面部初现，读取基本信息
Shot 4: 近景（Close-up）— 固定 2-3s — 记忆点特征（表情/标志物）
```

### 变体

**A. 神秘揭示**（先局部后全貌）
```
Shot 1: 特写 — 局部细节（手/脚/物件），不知是谁，3s
Shot 2: 中景 — 露出半身，仍有遮挡，3s
Shot 3: 全景 — 完全显露，4s
Shot 4: 近景 — 面部+标志特征，3s
```
变化：景别顺序反转（从近到远再到近），制造"先给线索再给答案"的悬念。

**B. 环境揭示**（逐层剥开空间）
```
Shot 1: 大远景 — 宏观地理（城市/山脉/海面），5s
Shot 2: 远景 — 特定区域（一栋建筑/一条街），4s
Shot 3: 中景 — 空间内部（房间/角落），3s
Shot 4: 特写 — 空间中的关键物件（桌上的信/墙上的照片），3s
```

**C. 加速揭示**（节奏递增）
```
Shot 1: 远景 — 5s（最慢，完整消化）
Shot 2: 全景 — 3s（加速）
Shot 3: 中景 — 2s（再加速）
Shot 4: 近景 — 1.5s（最快，冲击）
```
适用于紧迫感递增的入场（反派登场、时间紧迫的到达）。

### 节奏参数
| 参数 | 标准值 | 紧张变体 | 舒缓变体 |
|------|--------|---------|---------|
| 总时长 | 12-16s | 8-10s | 16-22s |
| 单镜时长 | 3-4s | 1.5-3s | 4-6s |
| 运镜占比 | 50% | 30% | 60% |

## 模板 2: 情绪聚焦（Emotional Focus）

**适用**：情绪逐步加强、角色内心变化、决定性时刻、从理性到感性

### 标准流
```
Shot 1: 中景（Medium Shot）— 固定 3s — 角色在环境中，情绪尚可控
Shot 2: 中近景（Medium Close-up）— 微推 3s — 开始读取表情细节
Shot 3: 近景（Close-up）— 固定 3-4s — 情绪完全占据画面
Shot 4: 特写（Extreme Close-up）— 固定 2-3s — 极端情绪的最终表达（眼泪/颤抖的嘴唇/瞳孔）
```

### 变体

**A. 情绪爆发型**（加速 + 打断）
```
Shot 1: 中景 — 3s — 平静
Shot 2: 近景 — 2s —（跳过中近景，加速聚焦）
Shot 3: 特写 — 1.5s — 极端表情
Shot 4: 远景 — 突然拉远 4s —（爆发后的空虚/余波）
```
变化：在 Shot 3→4 之间的景别大跨度（特写→远景）制造情绪断裂感。

**B. 平行情绪对比**（两个角色的情绪同步升级）
```
Shot 1: 双人中景 — 3s — 两人同框，建立关系
Shot 2: 角色A 近景 — 2s — A 的反应
Shot 3: 角色B 近景 — 2s — B 的反应
Shot 4: 角色A 特写 — 2s — A 情绪到达顶点
Shot 5: 角色B 特写 — 2s — B 情绪到达顶点
Shot 6: 双人中景 — 3s — 回到两人关系（变化后的）
```

**C. 无声情绪**（纯视觉叙事，无对白）
```
Shot 1: 中景固定长镜 — 5s — 角色表面平静
Shot 2: 近景极缓推 — 5s — 渐入内心
Shot 3: 特写固定 — 4s — 微小的表情变化是唯一的"动作"
```
适用于内心戏、失声痛哭前的沉默、无声的崩溃。

### 节奏参数
| 参数 | 标准值 | 急速变体 | 沉浸变体 |
|------|--------|---------|---------|
| 总时长 | 11-14s | 7-9s | 14-20s |
| 单镜时长 | 2-4s | 1.5-2.5s | 3-5s |
| 运镜占比 | 30% | 20% | 40%（极缓） |

## 模板 3: 震撼揭示（Shocking Reveal）

**适用**：揭示真相、规模展示、反转时刻、"原来如此"

### 标准流
```
Shot 1: 特写（角色反应）— 固定 2-3s — 震惊/恐惧/不敢相信的表情
Shot 2: 急拉至远景/全景 — 0.5-1.5s — 揭示引起反应的全貌
Shot 3: 回到近景（角色消化）— 3-4s — 角色理解/接受/崩溃
```

### 变体

**A. 双重揭示**（先揭一半，再揭全部）
```
Shot 1: 特写反应 — 2s
Shot 2: 中景半揭示 — 2s —（观众只看到一部分）
Shot 3: 更震惊的特写反应 — 1.5s
Shot 4: 急拉至远景完整揭示 — 1.5s
```

**B. Dolly Zoom 揭示**（空间扭曲型）
```
Shot 1: 中景 — Dolly Zoom 3s —（背景拉近但人物不变大，Vertigo 效果）
Shot 2: 远景 — 急切 1s —（揭示被扭曲的空间的真实样貌）
```
注意：Dolly Zoom 效果 AI 模型支持有限，prompt 中用 `background warping while subject stays fixed` 描述。

**C. 延迟揭示**（制造期待后再给答案）
```
Shot 1: 特写反应 — 3s —（角色看到了什么？观众还不知道）
Shot 2: 角色的身体语言变化 — 中景 3s —（退后？上前？颤抖？）
Shot 3: 极缓推向揭示物 — 远景→中景 5s —（终于揭示）
```

### 节奏参数
| 参数 | 标准值 | 急速冲击 | 慢燃揭示 |
|------|--------|---------|---------|
| 总时长 | 6-10s | 4-6s | 10-16s |
| 反应镜头 | 2-3s | 1-2s | 3-5s |
| 揭示镜头 | 0.5-2s | 0.5-1s | 3-5s |

## 模板 4: 对话基础（Standard Dialogue）

**适用**：标准对话、日常交流、信息传递

### 标准流
```
Shot 1: 双人中景 — 固定 3-4s — 建立两人空间关系
Shot 2: 正打 A — 过肩中近景 3-4s — A 说话
Shot 3: 反打 B — 过肩中近景 3-4s — B 回应
Shot 4: 正打 A — 近景 2-3s — A 的关键反应
Shot 5: 双人中景 — 固定 3s — 回归关系，结束段落
```

### 变体

**A. 穿插型**（打破正反打的单调）
```
Shot 1: 双人中景 — 3s
Shot 2: 正打 A（过肩） — 3s
Shot 3: 插入特写（手/物件/环境细节）— 2s —（打破节奏）
Shot 4: 反打 B（过肩） — 3s
Shot 5: 侧面双人中景 — 3s —（换了角度的双人镜）
```

**B. 行走对话**（边走边聊）
```
全程横移跟拍（Tracking Shot），双人中景
偶尔切入单人近景读表情
关键台词时停下脚步→固定近景
```

**C. 三人/多人对话**
```
Shot 1: 三人全景 — 建立空间关系
Shot 2-4: 轮流单人中近景（说话者）
Shot 5: 倾听者的反应特写（重点——不说话的人的反应往往更重要）
Shot 6: 回到全景
```
注意：多人对话避免全程正反打——会让观众像看乒乓球，每 3-4 个正反打穿插一个全景或反应特写。

### 节奏参数
| 参数 | 标准值 | 快节奏 | 慢节奏 |
|------|--------|--------|--------|
| 正反打单镜时长 | 3-4s | 2-3s | 4-6s |
| 双人镜时长 | 3-4s | 2-3s | 4-5s |
| 正反打/其他比例 | 60:40 | 70:30 | 50:50 |

## 模板 5: 对话升级（Escalating Dialogue）

**适用**：争吵、审讯、对峙、从平静到爆发

### 标准流
```
Phase 1（平静期）:
  Shot 1: 双人中景 — 固定 4s — 表面和平
  Shot 2-3: 正反打中近景 — 各 3-4s — 正常对话节奏

Phase 2（升温期）:
  Shot 4-5: 正反打收紧至近景 — 各 2-3s —（景别收紧 = 压力增加）
  运镜：加入微推（每镜缓推 10-15%）

Phase 3（爆发期）:
  Shot 6: 单人特写 — 手持微晃 2s — 情绪失控的表情
  Shot 7: 对方特写 — 1.5s — 被冲击的反应
  Shot 8: 双人中景（侧面/后方新角度）— 3s — 新构图暗示关系已变
```

### 变体

**A. 冷战型升级**（不爆发，但越来越冷）
```
景别始终维持中景~中近景（不收紧至特写）
但运镜从固定→逐步变为极缓推近
色调从暖→冷
最后一镜：双人中景，两人之间的空间明显变大（物理距离=心理距离）
```

**B. 单方压迫型**（一方压制，另一方被压）
```
压制者：始终中景~中近景，平角或微仰，稳定
被压者：逐步从中景收至特写，微俯角加重，运镜不稳
对比蒙太奇式交替，两人的"镜头待遇"差异=权力差异
```

### 节奏参数
| 参数 | Phase 1 | Phase 2 | Phase 3 |
|------|---------|---------|---------|
| 单镜时长 | 3-4s | 2-3s | 1.5-2s |
| 运镜 | 固定 | 微推 | 手持 |
| 景别 | 中景~中近景 | 中近景~近景 | 近景~特写 |

## 模板 6: 动作段落（Action Sequence）

**适用**：打斗、追逐、战斗、体育竞技

### 标准流
```
Shot 1: 全景 — 固定 3-4s — 建立战场/追逐路线
Shot 2: 中景 — 手持跟拍 2-3s — 核心动作
Shot 3: 特写 — 固定或急推 1-2s — 冲击瞬间（拳头/爆炸/碰撞）
Shot 4: 全景 — 固定 3s — 结果/后果
```

### 变体

**A. 持续追逐**（连续动态，不停歇）
```
Shot 1: 全景横移 — Steadicam 跟拍奔跑者 4s
Shot 2: POV 镜头 — 追逐者视角 2s
Shot 3: 中景 — 转角/跳跃等关键动作节点 2s
Shot 4: 远景 — 展示距离差（追上了还是拉开了）3s
循环 Shot 2-4 直到追逐结束
```

**B. 一对一格斗**
```
Shot 1: 双人全景 — 对峙 3s
Shot 2-5: 中近景交替 — 攻防回合 各 1.5-2s
Shot 6: 特写 — 决胜一击 1s
Shot 7: 全景 — 结果（一方倒下）3s
```

**C. 慢动作点睛**（关键瞬间减速）
```
正常速度动作流中，在冲击瞬间插入 1 个慢速特写（0.5-1s → 拉长至 2-3s）
慢速镜之后立刻恢复正常速度，对比制造冲击
一段动作最多 1-2 个慢速点（多了就疲劳）
```

### 节奏参数
| 参数 | 标准值 | 暴力冲击 | 优雅武术 |
|------|--------|---------|---------|
| 单镜时长 | 2-3s | 1-1.5s | 3-5s |
| 运镜占比 | 80% | 90% | 60% |
| 主要运镜 | 手持+横移 | 手持+甩镜 | Steadicam+环绕 |
| 建立/结果镜 | 3-4s | 2-3s | 4-5s |

## 模板 7: 孤独 / 离别（Loneliness / Departure）

**适用**：告别、离开、独自面对、失去、遗憾

### 标准流
```
Shot 1: 近景 — 固定 3-4s — 捕捉最后的情绪表情
Shot 2: 缓拉至远景 — 5-8s — 角色在画面中逐渐缩小
```

### 变体

**A. 渐行渐远型**
```
Shot 1: 双人近景 — 3s — 最后的亲密
Shot 2: 单人中景 — 角色转身离开 3s
Shot 3: 远景固定 — 角色背影越来越小 5-8s
Shot 4: 大远景 — 角色消失在环境中 3-5s（可选）
```

**B. 留下的人**（视角在被留下的一方）
```
Shot 1: 过肩中景 — 从留下者的肩后看离开者 3s
Shot 2: 近景 — 留下者的表情（目送/强忍/崩溃）4s
Shot 3: POV — 留下者视角看到空荡的门/路/座位 3s
Shot 4: 远景 — 留下者在空间中独自站立 5s
```

**C. 死亡 / 永别**
```
Shot 1: 双人近景 — 最后的对视/触碰 5s（长镜，不剪）
Shot 2: 特写 — 手指松开/眼睛闭上 3s
Shot 3: 极缓拉至远景 — 8-10s — 让"离开"的过程本身成为叙事
（全程无运镜变化，仅拉远这一个动作）
```

### 节奏参数
| 参数 | 标准值 | 克制型 | 崩溃型 |
|------|--------|--------|--------|
| 总时长 | 8-15s | 6-10s | 12-20s |
| 拉远速度 | 极缓（5-8s） | 中缓（3-5s） | 极缓（8-10s） |
| 固定镜时长 | 3-4s | 2-3s | 4-5s |
| 运镜 | 缓拉 | 缓拉 | 缓拉+微升（俯瞰） |

## 模板 8: 群戏高潮（Ensemble Climax）

**适用**：团队集结、庆祝胜利、最终对决、全员亮相

### 标准流
```
Shot 1-N: 各角色特写快切 — 每人 1-2s — 逐一展示
Shot N+1: 全景/远景 — 环绕或升降 4-6s — 所有人同框
```

### 变体

**A. 集结型**（从分散到汇合）
```
Shot 1: 角色A 中景 — 从某方向走来 2s
Shot 2: 角色B 中景 — 从另一方向走来 2s
Shot 3: 角色C 中景 — 再一个方向 2s
Shot 4: 全景 — 三人在中心汇合 4s
Shot 5: 升降至鸟瞰 — 展示完整阵容 3s
```

**B. 情绪共振型**（同一情绪的不同表达）
```
Shot 1: 角色A 近景 — 微笑 1.5s
Shot 2: 角色B 近景 — 含泪微笑 1.5s
Shot 3: 角色C 近景 — 沉默点头 1.5s
Shot 4: 角色D 近景 — 大笑 1.5s
Shot 5: 全景 — 所有人一起，环绕镜头 5s
```
变化：每个特写中角色的反应不同但情绪内核相同，制造"殊途同归"的感动。

**C. 全员战斗型**
```
Shot 1: 全景 — 对峙全貌 3s
Shot 2-5: 各角色中景快切 — 各自的战斗姿态/武器 各 1s
Shot 6: 远景 — 全员冲锋/集体动作 4s
Shot 7: 中近景混剪 — 各自战斗亮点 各 1-2s
Shot 8: 全景 — 尘埃落定 4s
```

### 节奏参数
| 参数 | 2-3 人 | 4-6 人 | 7+ 人 |
|------|--------|--------|-------|
| 个人镜头时长 | 2-3s | 1.5-2s | 1-1.5s |
| 全景时长 | 4-5s | 5-6s | 6-8s |
| 总时长 | 8-14s | 12-18s | 15-25s |

## 模板组合：多模板串联

实际场景经常需要串联多个模板。常见组合：

| 场景 | 模板串联 | 总时长参考 |
|------|---------|----------|
| 角色入场→对话 | 渐进揭示 → 对话基础 | 25-35s |
| 对话→争吵→打斗 | 对话基础 → 对话升级 → 动作段落 | 35-50s |
| 环境建立→角色入场→内心独白 | 渐进揭示(环境) → 渐进揭示(角色) → 情绪聚焦 | 30-45s |
| 团队集结→战斗→胜利 | 群戏高潮(集结) → 动作段落 → 群戏高潮(庆祝) | 40-60s |
| 发现真相→情绪崩溃→离别 | 震撼揭示 → 情绪聚焦 → 孤独/离别 | 25-40s |

### 串联过渡规则
- 模板之间需要 **1 个过渡镜头**（2-3s），用于衔接不同情绪段落
- 过渡镜头推荐：环境空镜（天空/水面/建筑）/ 角色沉默的中景 / 物件特写
- 两个高强度模板之间（如动作→动作）必须有 ≥3s 的"着陆"镜头
- 从慢节奏模板到快节奏模板→过渡镜头用短促运镜"启动"加速
- 从快节奏模板到慢节奏模板→过渡镜头用固定长镜"刹车"
