# 电影级镜头决策引擎 — Cinematic Camera Engine

输入场景描述，自动输出完整的镜头方案：**用什么景别、怎么运镜、什么角度、配什么焦段、镜头之间怎么衔接**。

**核心理念**：镜头语言不是随机选择——每种景别、运镜、角度都携带情绪和叙事信息。
本 Skill 将选择逻辑系统化，从"凭感觉选镜头"升级为"按规则匹配最优镜头方案"。

**与其他 Skill 的关系**：
- `cinematic-grammar-glossary` = 镜头**词典**（"推镜头是什么"）→ 术语查阅
- **本 Skill** = 镜头**引擎**（"这个场景应该用什么镜头"）→ 方案决策
- `video-prompt-craft` = 提示词**工坊**（将镜头方案写成 Seedance 可用的时间码 prompt）→ 产出执行
- `epic-cinematic-lighting` = 光影设计（与本 Skill 正交使用，光影+镜头共同构成画面）

---

## 铁律（选镜头前必读）

1. **景别必须匹配叙事功能**：展示环境→远/全景，交代关系→中景，传递情绪→近/特写。反过来用 = 观众读不到信息
2. **相邻镜头景别至少跨 2 级**：中景→中景 = 跳切感；中景→近景(跨1级) = 勉强；中景→特写(跨2级) = 流畅。因为 AI 模型对微小景别差异不敏感，跨 2 级才能产生可见区分
3. **每个运镜必须有叙事理由**：推近 = 引导注意力聚焦；拉远 = 揭示环境/孤独；横移 = 跟随/扫描。无理由运镜 = 晃动干扰
4. **机位角度传递权力关系**：仰拍 = 被摄对象强大/威严；俯拍 = 被摄对象渺小/脆弱；平拍 = 平等/客观。角度与剧情矛盾 = 观众潜意识不适
5. **一个镜头只做一件事**：要么展示空间，要么传递情绪，要么交代动作。同时做三件事 = AI 模型全部做不好
6. **运镜速度匹配情绪节奏**：紧张→快速运镜/手持晃动；平静→缓慢推移/固定机位。速度和情绪不匹配 = 观众感觉"哪里不对"

## 反模式

| 反模式 | 翻车原因 | 正确做法 |
|--------|---------|---------|
| 全部用中景 | 观众无法区分重要性层级 | 按信息层级分配景别：环境→全景，关系→中景，情绪→特写 |
| 连续 3 个以上相同景别 | 视觉疲劳 + AI 模型生成相似构图 | 最多连续 2 个同景别，第 3 个必须跳级 |
| 运镜写"推镜头"三个字 | 缺起终点 = AI 随机运动 | 写 `Slow dolly in from medium shot to close-up, ending on character's eyes` |
| 对话全用正反打 | 机械、无变化 | 正反打中穿插过肩镜头、双人中景、反应特写 |
| 激烈场景用固定机位 | 画面静止 vs 剧情激烈 = 割裂 | 手持/Steadicam + 速度变化 |
| 每个镜头都有运镜 | 观众眼睛累，运镜变噪音 | 运镜:固定 ≈ 3:7（日常）/ 5:5（动作）/ 7:3（追逐） |
| 写"特写镜头"但不说特写什么 | AI 随机选择特写对象 | `Extreme close-up on trembling fingers gripping the letter` |

## STEP 0: 场景分析 → 镜头方案自动选择（决策引擎核心）

收到场景/分镜/剧情描述后，按以下决策树选择镜头方案：

```
输入：场景描述 / 分镜脚本 / 情绪关键词
  │
  ├─ 提取 4 要素：
  │   ❶ 场景类型（对话/动作/独白/环境/转场/群戏...）
  │   ❷ 情绪基调（平静/紧张/温馨/悲伤/震撼/恐惧/喜悦/愤怒）
  │   ❸ 动作强度（静态/轻度/中度/激烈）
  │   ❹ 人物数量（0/1/2/多人）
  │
  ├─ 查表匹配：
  │   → references/scene-camera-recipes.md（12种场景 × 完整镜头方案）
  │   → references/shot-flow-patterns.md（多镜头衔接模板）
  │
  ├─ 输出完整镜头方案：
  │   景别 + 运镜 + 角度 + 焦段 + 构图要点
  │
  └─ Fallback（信息不足时）：
      默认 = 中景 + 固定机位 + 平角 + 50mm + 三分法
      输出时标注「已使用默认中性镜头方案，如需调整请提供场景情绪」
```

### 场景类型速判

| 场景关键词 | 场景类型 | 默认起始景别 |
|-----------|---------|------------|
| 对话/聊天/争吵/告白/审讯 | 对话场景 | 双人中景 → 正反打 |
| 打斗/追逐/逃跑/爆炸 | 动作场景 | 全景建立 → 中近景动作 |
| 独白/回忆/思考/凝视 | 内心戏 | 近景/特写 |
| 走进/到达/进入/来到 | 角色入场 | 远景→中景→近景（渐进式揭示） |
| 城市/山脉/海洋/建筑/空间 | 环境展示 | 大远景/远景 |
| 第一次出现/亮相/登场 | 角色首秀 | 全景建立→中景定位→特写记忆点 |
| 分别/离开/结束/死亡 | 告别/结局 | 近景→拉远至远景 |
| 发现/揭示/真相/震惊 | 揭示时刻 | 特写反应→拉远揭示全貌 |
| 等待/孤独/无聊/寂寞 | 静态情绪 | 远景（人在空间中渺小）|
| 庆祝/欢呼/胜利/团聚 | 群戏高潮 | 中景→全景（涵盖所有人）|
| 过渡/时间流逝/蒙太奇 | 转场段落 | 混合景别快切 |
| 恐惧/跟踪/偷窥/危险 | 悬疑/恐怖 | POV + 荷兰角 + 手持 |

## STEP 4: 镜头流（Shot Flow）— 衔接与节奏

镜头不是孤立存在的——**一组镜头如何衔接**决定叙事节奏。

### 经典镜头序列模板

| 模板名称 | 镜头流 | 适用场景 |
|---------|--------|---------|
| 渐进揭示 | 远景→全景→中景→近景 | 角色入场、环境建立 |
| 情绪聚焦 | 中景→中近景→近景→特写 | 情绪逐步加强 |
| 震撼揭示 | 特写(反应)→急拉至远景 | 揭示真相、规模展示 |
| 对话基础 | 双人中景→正反打(中近景)→反应特写 | 标准对话 |
| 对话升级 | 中景→近景→特写(随冲突升级景别收紧) | 争吵、审讯 |
| 动作段落 | 全景(建立)→中景(动作)→特写(冲击)→全景(结果) | 打斗、追逐 |
| 孤独/离别 | 近景(情绪)→缓拉至远景(人在空间中缩小) | 告别、失落 |
| 群戏高潮 | 各角色特写快切→全景(所有人) | 团队集结、庆祝 |

### 镜头衔接铁律

| 规则 | 原因 | 违反后果 |
|------|------|---------|
| 相邻镜头景别跨 ≥2 级 | 跨 1 级 AI 模型生成画面差异太小 | 观众感觉"跳了一下" |
| 运镜方向一致性 | 连续两个镜头的运动方向不能 180° 反向 | 观众空间感混乱 |
| 轴线不越 | 两人对话保持同侧拍摄 | 观众分不清谁在哪边 |
| 固定镜头后接运镜 | 全部固定→沉闷；全部运镜→晕 | 节奏丧失呼吸感 |
| 快切段落后接长镜 | 持续快切→疲劳 | 需要"着陆点"让观众喘息 |

> 完整的镜头序列模板和变体见 `references/shot-flow-patterns.md`。
> 完整的场景→镜头配方见 `references/scene-camera-recipes.md`。

## STEP 6: 自检（黑盒执行，不输出给用户）

生成镜头方案后，静默检查以下 6 项：

1. ✅ 相邻镜头景别是否跨 ≥2 级？
2. ✅ 运镜是否有叙事理由？（不是为了运镜而运镜）
3. ✅ 机位角度是否匹配权力关系？
4. ✅ 一个镜头是否只做一件事？
5. ✅ 运镜速度是否匹配情绪节奏？
6. ✅ 是否存在连续 3+ 个相同景别？

未通过 → 自动修正后输出，不告知用户检查过程。

## STEP 7: 跨镜头色彩一致性锁定

多镜头项目中，**色彩漂移**是最常见的视觉断裂问题——同一个场景的不同镜头
色温/饱和度/色调不统一，剪在一起像跳戏。

### 规则

1. **色彩参考镜头必须指定**：多镜头序列中，第一个定稿的镜头自动成为该序列的"色彩锚点"。后续镜头必须参考该锚点的色调
2. **色彩描述必须量化**：不能写"冷色调"→ 必须写具体参数：`desaturated ~40%, teal-grey dominant, Kodak Vision3 500T`
3. **全片色彩基调锁定**：项目开始时确定全片色彩体系（色温/饱和度范围/主色调），写入项目分镜剧本的「媒介风格锁」段落。每个镜头方案的 Prompt 片段必须包含该色彩锁定语句
4. **色彩变化需叙事理由**：从冷色切暖色 = 情绪转折点。无理由的色彩跳变 = bug

### 典型教训

40个镜头各自独立生成 → 有的偏暖黄、有的偏冷蓝、有的饱和度正常 →
剪在一起色彩乱跳。**事后统一色调 = 每张都要重新编辑，不如一开始就锁住。**

### 色彩锚点 Prompt 模板

```
Color grade anchor: [从定稿锚点镜头提取的色彩描述]
Example: "Desaturated cold teal-grey palette ~40% saturation, 
Kodak Vision3 500T pushed 1 stop, silver-retention/bleach-bypass, 
heavy 35mm grain. Skin tones shifted olive-grey."
```

此模板粘贴到每个镜头方案的 Prompt 片段开头。
